How to get your Wix API Key

1
Open the Wix API Keys Manager
In your Wix Enterprise or Studio dashboard, go to Settings → API Keys Manager. This is only available on Enterprise and Studio accounts.
Wix Dashboard → Settings → API Keys Manager
2
Generate a new API key
Click + Generate API Key. Give it a name like "Forge AI". Under permissions, enable Site List access and set it to All Sites.
3
Copy your API Key and Account ID
After generating, copy the API key — it is only shown once. Your Account ID is shown on the same screen.
API Key: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
4
Enter your credentials above
Click Connect with API Key above, paste your API Key and Account ID, then click Find My Sites.

Frequently asked questions

Do I need a Wix Enterprise account? ▼
Only for the API Key connection. Standard Wix accounts cannot generate API keys. However, you can still monitor any Wix site by adding it via URL — this works on all Wix plans.
What's the difference between API Key and Add by URL? ▼
API Key connection automatically discovers all sites on your Wix account — ideal for agencies managing multiple Wix clients. Add by URL lets you monitor any single Wix site without API access.
Is my API key stored securely? ▼
Yes. Your API key is encrypted and stored securely in our database. It is only used to fetch your site list from the Wix API and is never exposed to the client.
When will I get alerts? ▼
Forge AI scans your Wix sites every morning and alerts you only if a score drops 10 or more points since the last scan. Uptime is checked every 5 minutes around the clock.
Can I add more Wix sites later? ▼
Yes. Come back to this page anytime to add additional sites via API Key or URL. You can also add Wix sites directly from the dashboard.
