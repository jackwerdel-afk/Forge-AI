Install WordPress Plugin
Connect any WordPress site to Forge AI in under 2 minutes. Get real-time building alerts, AI auto-fix, and daily automated scans.

Forge AI WordPress Plugin

Version 1.2.0 — Compatible with WordPress 5.0+

⬇ Download Plugin
💡 You'll need your Forge AI Token during setup. It's shown on your dashboard above the platform connections section. Copy it before you start.
1

Download the plugin

Click the Download Plugin button above to download forge-ai-wordpress-plugin.zip to your computer. Do not unzip it — WordPress needs the ZIP file.

2

Go to your WordPress dashboard

Log into the WordPress site you want to connect. In the left sidebar click Plugins then click Add New Plugin.

WordPress Dashboard → Plugins → Add New Plugin
3

Upload the plugin

At the top of the page click Upload Plugin. Click Choose File and select the forge-ai-wordpress-plugin.zip file you just downloaded.

Plugins → Add New → Upload Plugin → Choose File → forge-ai-wordpress-plugin.zip
4

Install and activate

Click Install Now. Once it installs click Activate Plugin. You'll see Forge AI appear in your left sidebar.

Install Now → Activate Plugin → Forge AI appears in sidebar ✓
5

Enter your Forge AI token

Click Forge AI in the left sidebar. Paste your Forge AI token into the token field. Optionally add your Anthropic API key to enable AI auto-fix.

Forge AI → Token field → Paste fat_xxxxxxxxxxxxxxxx_... → Save & Connect
6

You're connected!

Forge AI is now monitoring this WordPress site. When you save or view any page Forge AI will detect issues and show a popup with exactly what's wrong and a Fix Now button to fix it instantly using AI.

✓ Connected — Real-time alerts active — AI auto-fix ready

Frequently asked questions

What does the Anthropic API key do?
It enables the AI auto-fix feature. When Forge AI finds an issue like a missing meta description it uses Claude AI to write a proper fix and applies it automatically with one click. Without the key alerts still work but the Fix Now button won't be available.
Where do I find my Forge AI token?
Go to your Forge AI dashboard and look for the "Your Forge AI Token" section above your client sites. Click Copy to copy it.
Does this work with any WordPress theme?
Yes — Forge AI works with any WordPress theme including Elementor, Divi, Astra, and block themes.
Will it slow down my site?
No — the monitoring script only loads for logged-in users. Your site visitors never see it and it has no impact on page speed.
How do I disconnect a site?
Go to Forge AI in your WordPress sidebar and click "Disconnect site" at the bottom of the page.
