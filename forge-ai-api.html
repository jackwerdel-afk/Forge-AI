GET /sites
Returns all sites in your agency account with their current health scores.
Example Request
curl
curl https://forgeai-wgs.com/api/forge-api/sites \
  -H "Authorization: Bearer YOUR_TOKEN"
Example Response
json
{
  "success": true,
  "count": 3,
  "sites": [
    {
      "id": "abc123",
      "name": "Client Site",
      "url": "https://clientsite.com",
      "platform": "wordpress",
      "score": 87,
      "grade": "B",
      "lastScanned": "2026-07-24T08:00:00Z",
      "client": { "name": "Jane Smith", "email": "jane@client.com" }
    }
  ]
}
GET /sites/:url
Returns detailed health data for a specific site including issues and score history. URL-encode the site URL.
Example Request
curl
curl "https://forgeai-wgs.com/api/forge-api/sites/https%3A%2F%2Fclientsite.com" \
  -H "Authorization: Bearer YOUR_TOKEN"
Example Response
json
{
  "success": true,
  "site": {
    "id": "abc123",
    "name": "Client Site",
    "url": "https://clientsite.com",
    "score": 87,
    "grade": "B",
    "lastScanned": "2026-07-24T08:00:00Z",
    "issues": [
      { "type": "missing_meta", "severity": "high", "description": "5 pages missing meta descriptions" }
    ],
    "scoreHistory": [
      { "score": 82, "date": "2026-07-17T08:00:00Z" },
      { "score": 87, "date": "2026-07-24T08:00:00Z" }
    ]
  }
}
POST /scan
Triggers an immediate health scan on a site. Returns 202 Accepted immediately — the scan runs asynchronously and results appear on your dashboard within 1-2 minutes.
Request Body
ParameterTypeRequiredDescription
urlstringRequiredThe full URL of the site to scan
Example Request
curl
curl -X POST https://forgeai-wgs.com/api/forge-api/scan \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://clientsite.com"}'
Example Response
json
{
  "success": true,
  "message": "Scan triggered. Results will be available shortly.",
  "url": "https://clientsite.com"
}
GET /reports
Returns the last 50 client reports sent from your account.
Example Request
curl
curl https://forgeai-wgs.com/api/forge-api/reports \
  -H "Authorization: Bearer YOUR_TOKEN"
POST /report/send
Sends a white-label health report to a client email address.
Request Body
ParameterTypeRequiredDescription
urlstringRequiredThe site URL to report on
clientEmailstringRequiredClient's email address
clientNamestringOptionalClient's name for personalization
Example Request
curl
curl -X POST https://forgeai-wgs.com/api/forge-api/report/send \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://clientsite.com","clientEmail":"jane@client.com","clientName":"Jane"}'

CodeMeaning
