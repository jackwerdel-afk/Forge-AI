How to add your Webflow site

1

Find your Webflow site URL

Your Webflow site URL is either your custom domain (e.g. yoursite.com) or the default Webflow staging URL (yoursite.webflow.io).

Webflow Designer → Publish → View published site → copy URL
2

Publish your Webflow site

Forge AI can only monitor published Webflow sites. Click Publish in the Webflow Designer if the site is not already live.

3

Enter the URL below

Paste your Webflow site URL below, add an optional name, and click Add & Monitor. Forge AI will add it immediately and run a full scan.

Frequently asked questions

Should I use my custom domain or the .webflow.io URL?
Use your custom domain if you have one connected — that is what your visitors see and what Google indexes. The .webflow.io staging URL works but your custom domain is preferred.
Can I monitor multiple Webflow sites?
Yes. Add each site separately by URL. Each gets its own dashboard card with individual daily scans and score alerts.
Why no live editor alerts on Webflow?
Live editor alerts require a plugin installed inside the CMS editor. Webflow does not support third-party editor plugins in the same way WordPress does. Forge AI monitors Webflow sites daily instead.
When will I get alerts?
Only when something changes. Forge AI scans your site every morning and alerts you only if the score drops 10 or more points since the last scan.
Will analytics tracking work on Webflow?
Analytics tracking for Webflow sites is coming soon. You will be able to add a tracking snippet via Webflow custom code settings to enable visitor analytics in Forge AI.
