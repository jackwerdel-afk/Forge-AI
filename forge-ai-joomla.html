How to add your Joomla site

1

Find your Joomla site URL

Your Joomla site URL is the public domain where the site is hosted — for example yourclient.com. You can find it in Joomla Admin → System → Global Configuration → Site → Site URL.

Joomla Admin → System → Global Configuration → Site URL

Enter the URL below

Paste the Joomla site URL below and click Add & Monitor. Forge AI will run an immediate scan and schedule daily monitoring.

Frequently asked questions

Does this work with Joomla 3 and Joomla 4?
Yes. Forge AI monitors the public URL regardless of the Joomla version.
Will Forge AI access my Joomla admin panel?
No. Forge AI only reads publicly accessible front-end pages. Your admin panel is never accessed.
Can I monitor multiple Joomla sites?
Yes. Add each site URL separately. All sites appear in your Forge AI dashboard with individual scans and alerts.
