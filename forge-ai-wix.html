How to get your Wix API Key

1

Open the Wix API Keys Manager

In your Wix Enterprise or Studio dashboard, go to Settings → API Keys Manager. This is only available on Enterprise and Studio accounts.

Wix Dashboard → Settings → API Keys Manager
2

Generate a new API key

Click + Generate API Key. Give it a name like "Forge AI". Under permissions, enable Site List access. Set it to access All Sites.

3

Copy your API Key and Account ID

After generating, copy the API key — it is only shown once. Your Account ID is shown on the same screen. Copy both.

API Key: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
4

Enter your credentials below

Paste your API Key and Account ID in the fields below. Click Find My Sites — Forge AI will connect to your Wix account and list all your sites.

Frequently asked questions

Why do I need a Wix Enterprise or Studio account?
Wix API keys are currently only available to Enterprise and Studio accounts. Standard Wix accounts do not have access to the API Keys Manager. If you are on a standard account, you can still monitor your Wix sites by adding them by URL from the dashboard.
Is my API key stored securely?
Your API key is never stored by Forge AI. It is only used in the moment you click "Find My Sites" to fetch your site list, then discarded. We never persist API keys in our database.
Can I add more sites later?
Yes. Come back to this page anytime, enter your credentials again, and add any new sites to your dashboard.
What permissions does the API key need?
The API key only needs Site List read access. Forge AI does not need write access or access to any other Wix data.
When will I get alerts?
Forge AI scans your sites every morning and alerts you only if a score drops 10 or more points since the last scan.
